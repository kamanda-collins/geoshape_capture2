# Geo Shape Capture Portal

A GIS MVP application for collecting polygon data.

## Getting Started

1. Clone this repository
2. Install dependencies:
```bash
npm install
```
3. Start the development server:
```bash
npm run dev
```

## Features

- Interactive map interface
- Polygon shape drawing and editing
- GeoJSON data collection
- Layer management
- Location search functionality

## Development

This project is built with:
- React
- TypeScript
- Leaflet for mapping
- Vite for build tooling

## Deployment

To deploy the application:

1. Build the project:
```bash
npm run build
```

2. Deploy the contents of the `dist` directory to your hosting provider.

## Custom Domain Setup

To set up a custom domain:

1. Configure your DNS settings to point to your hosting provider
2. Set up SSL certificates
3. Configure your hosting provider to serve the application
